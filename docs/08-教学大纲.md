# 08 · 教学大纲（3 小时工作坊）

> 目标：让零后端经验的人，在一节课内拥有一个能发给真实模特的选片网站。
> 建议形式：边讲边做，每段都有"可验收的产物"，不追求讲完所有代码。

## 课前准备

学员需要：

- 一台电脑 + Chrome/Edge
- Node.js 20+
- GitHub 账号（用于托管代码）
- 一个可以部署的账号（或直接用本机 + 内网穿透演示）

讲师准备：

- 本仓库模板跑通一遍
- 一份"坏样例"用于演示踩坑（把 `model-api.js` 改成相对路径即可复现链接过期）
- 一个已上线的示例站点

## 时间分配

| 时段 | 模块 | 产出 |
|---|---|---|
| 0:00–0:15 | 开场：看成品、拆需求 | 一张流程图 |
| 0:15–0:45 | 模块一：页面与设计规范 | 能打开的静态页面 |
| 0:45–1:15 | 模块二：本地照片库 | 上传 + 网格 + 图片显示 |
| 1:15–1:40 | 模块三：登录与密码 | 本机密码闸门 |
| 1:40–2:05 | 模块四：选片交互 | 勾选、暂存、确认 |
| 2:05–2:40 | 模块五：分享链接 + 部署 | 手机能打开的链接 |
| 2:40–3:00 | 复盘：踩坑与升级路径 | 一份问题清单 |

## 模块零 · 开场（15 分钟）

**讲**：

- 演示完整流程：上传 → 勾选 → 生成链接 → 手机打开 → 提交 → 导出清单
- 只问三个问题：谁用？数据放哪？什么算做完？

**做**：学员在纸上画自己的流程图（角色、入口、数据流向）。

**验收**：能说出"照片存在哪、链接里有什么"。

## 模块一 · 页面与设计规范（30 分钟）

**讲**：

- 双角色两个页面，靠入口区分
- 设计 token：底色、主色、强调色各只有一个职责
- 响应式断点：2/3/4/5 列

**做**：

- 打开 `template/public/index.html`，改标题、改 `--purple`、`--lime`
- 拖窗口宽度，观察网格变化

**验收**：自己的配色、自己的标题；375px 宽无横向滚动。

**常见问题**：改完没变化 → 强刷缓存（Ctrl+Shift+R）。

## 模块二 · 本地照片库（30 分钟）

**讲**：

- 为什么照片存 IndexedDB 而不是 localStorage（容量、二进制）
- canvas 压缩：长边 1600、质量逐级降、目标 ≤900KB
- 为什么 `<img>` 需要 Service Worker

**做**：

1. 上传 5 张照片
2. DevTools → Application → IndexedDB → `pick-local/photos` 查看记录
3. 离线刷新，确认图片仍显示

**验收**：断网后网格仍有图；同名再传有"跳过/覆盖"弹窗。

**演示坑**：把 `sw.js` 注册路径改成相对路径，看图片是否破图（对应 [07](07-踩坑与排查.md) 第 5 条）。

## 模块三 · 登录与密码（25 分钟）

**讲**：

- 只存哈希：PBKDF2 + 随机盐 + 迭代次数
- 常量时间比较
- 为什么不上传密码

**做**：

- 设置密码 → 退出 → 再登录
- DevTools 里检查 `localStorage`，确认没有明文

**验收**：错误密码有提示；旧密码在改密后失效。

**讨论题**：如果要做"多人协作"，密码应该放哪？（引到模块五的升级路径）

## 模块四 · 选片交互（25 分钟）

**讲**：

- 用 `Set<文件名>` 做选择状态的原因
- 草稿 vs 确认
- 快速模式与浏览模式

**做**：

- 勾 3 张 → 暂存 → 刷新恢复
- 筛选"已选/未选" → 分页 → 确认
- 复制文件名清单

**验收**：刷新后勾选不丢；确认后徽标"已提交"。

**常见问题**：勾了却没保存 → 看徽标是否显示"未保存"。

## 模块五 · 分享链接与部署（35 分钟）

**讲**：

- token 即身份
- 发布时上传压缩快照；失败要回滚
- 部署三要素：单进程、`PORT`、`0.0.0.0`
- 快照不持久意味着什么

**做**：

1. 生成链接，手机扫码/发给自己打开
2. 在模特页提交
3. 管理页等待通知，查看结果
4. 部署到公网（讲师带做或提供一键脚本）

**验收**：不同网络的手机能打开链接并提交；管理页收到通知。

**演示坑**：重新部署一次，让学员看到链接失效，再一起讨论怎么根治。

## 模块六 · 复盘（20 分钟）

**讲**：

- 三种存储方案的取舍（A/B/C）
- 什么信号出现时该升级架构
- 安全边界：token、密码、origin

**做**：每人写三条"如果明天要给客户用，我还缺什么"。

**收尾**：把仓库链接、示例站点、踩坑清单发到群里。

## 课后作业（可选）

1. 把你的版本部署上线，发一条真实链接
2. 改一版自己的配色与文案
3. 加一个小功能（任选）：
   - 场次搜索
   - 已选张数上限
   - 导出 CSV（文件名 + 是否选中）
   - 图片按上传时间/文件名排序切换
4. 写一段 200 字复盘：最难的坑是什么、怎么定位的

## 讲师提示

- 不要逐行讲代码：每个模块只讲 3 个关键函数，其余让学员对照仓库
- 每 10 分钟必须有一次"看得见的变化"
- 故意留一个可复现的 bug 让学员排查，比讲十遍原理有效
- 学员卡住时先问"Network 里那条请求是什么状态码"，80% 的问题当场能定位

## 评估标准

| 等级 | 标准 |
|---|---|
| 完成 | 本机能完整走通上传→选片→导出 |
| 及格 | 部署上线，手机能打开并提交 |
| 良好 | 能解释数据存在哪、链接为什么可能失效 |
| 优秀 | 能提出并实现一个持久化或安全改进 |
